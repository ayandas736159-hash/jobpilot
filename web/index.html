Install the extension (load unpacked)

  1. Clone this repository and keep the extension folder.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Choose “Load unpacked” and select the extension folder.
  5. Pin JobPilot. Click the icon to open the side panel.
  6. In Settings, paste your own Groq API key. It stays in chrome.storage.local.
  7. Try it on the local forms: Greenhouse / Lever sample and the application-question sample. Serve this web folder, or open those files from a local server. Chrome content scripts do not run on file:// pages unless you allow file access.

Privacy

The profile, resume, and API key stay in your browser. The extension sends the key only to api.groq.com, and only when you write an answer or resolve an ambiguous choice. Job pages never receive the key. There is no JobPilot server and no serverless function. The web tailor uses the same rule: a key you type is kept in localStorage on this device.
